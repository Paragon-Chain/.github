## Overview

Paragon Chain is focused on building a complete onchain ecosystem with clear product boundaries and long-term protocol architecture.

Our public GitHub organization is where we share approved repositories for the live Paragon stack, including protocol contracts, subgraphs, and ecosystem tooling.

## What We’re Building

- **DEX Infrastructure** for swaps, liquidity, routing, and market primitives
- **Payflow Systems** for programmable execution, relayers, rebates, and settlement
- **DAO Rails** for governance, incentives, fee distribution, and ecosystem coordination
- **Agent Products** for autonomous execution and agent-native integrations
- **Treasury Systems** for controlled protocol value flows and distribution logic
