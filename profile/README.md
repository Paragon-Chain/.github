## Overview

Paragon Chain is focused on building a full protocol ecosystem with clear product boundaries, strong smart contract architecture, and long-term composability.

This GitHub organization is the public home for approved Paragon repositories, including protocol contracts, indexing infrastructure, and ecosystem tooling. It is intended to be clean, professional, and easy to navigate for contributors, partners, auditors, and the wider community.

## What We’re Building

| Domain | Description |
| --- | --- |
| **DEX Infrastructure** | Core AMM primitives, liquidity routing, swap execution, and trading rails. |
| **Payflow Systems** | Programmable execution, relayers, rebate logic, settlement, and intent-based flows. |
| **DAO Infrastructure** | Governance, voting power, incentives, emissions, fee distribution, and ecosystem coordination. |
| **Agent Products** | Agent-native execution systems, permission rails, and autonomous interaction layers. |
| **Treasury Systems** | Controlled protocol value flows, treasury distribution, and reward-routing infrastructure. |

## Principles

- Build open and modular infrastructure
- Keep execution non-custodial wherever possible
- Separate public protocol repos from sensitive audit or R&D workspaces
- Maintain clean repository boundaries by product domain
- Document not only what each system does, but why it exists

## Public Repository Philosophy

This organization is meant to reflect the live and approved ParagonChain surface.

That means:

- live protocol repositories should stay clean and intentional
- audit snapshots should remain separate from public development repos
- unreleased ideas should not be mixed into public codebases
- repositories should be understandable to both users and technical reviewers

## Looking Ahead

Paragon Chain is being structured as more than a single app or contract package. The goal is a durable DeFi ecosystem with independent but connected protocol layers that can evolve over time without losing clarity or security.

As the ecosystem expands, this organization will continue to grow across contracts, subgraphs, tooling, interfaces, and agent-native infrastructure.
